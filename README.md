KeenKeeper – Keep Your Friendships Alive

KeenKeeper is a friendship management web application designed to help users maintain meaningful relationships by tracking interactions, monitoring contact goals, and viewing friendship analytics. Users can log calls, texts, and video chats to stay connected with their friends.

Live Site:https://keenkeeper-jet.vercel.app/

---

 Project Overview

KeenKeeper helps users keep track of their friendships by monitoring when they last contacted a friend and providing quick ways to log new interactions. The application includes a timeline of communication history and visual analytics to better understand relationship engagement.

---

 Technologies Used

* Next.js (App Router)
* React.js
* Tailwind CSS
* Recharts
* React Hot Toast
* React Icons
* JSON Data Storage
* Vercel (Deployment)

---

 Key Features

1. Friend Management

* View all friends in a responsive card layout.
* Track contact status (Overdue, Almost Due, On-Track).
* Access detailed friend profiles with contact information and goals.

2. Interaction Timeline

* Log Call, Text, and Video interactions instantly.
* Automatic timeline updates with date and activity details.
* Filter timeline entries by interaction type.

3. Friendship Analytics

* Visualize communication patterns using a Pie Chart.
* Track Call, Text, and Video interaction statistics.
* Responsive analytics dashboard powered by Recharts.

 Installation & Setup

Clone the repository:

```bash
git clone YOUR_REPOSITORY_LINK
```

Navigate to the project directory:

```bash
cd keenkeeper
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
